
# Dynamic Booking & Pricing Calculator

A lightweight, highly interactive frontend booking engine designed to increase e-commerce conversion rates by offering automated multi-tier volume discounts.

## 🚀 Business Features
- **Instant Price Computations:** Calculates total stay costs entirely client-side without annoying page refreshes.
- **Tiered Discount Incentives:** Boosts average order value (AOV) by unlocking a 10% discount at 5+ nights and a 20% discount at 10+ nights.
- **Strict Data Validation:** Prevents form submission errors and layout crashes by handling edge cases (negative numbers, text entries, and empty fields).

## 🛠️ Tech Stack & Concepts Used
- **Semantic HTML5:** Structured for optimal accessibility and search engine visibility.
- **Custom CSS3 Responsive Layout:** Styled into a clean UI module using Flexbox.
- **Vanilla JavaScript:** 
  - DOM element selection and inner text mutation.
  - Event Listeners for real-time input handling.
  - Strict Data Type handling using `parseInt()` to prevent type coercion calculation bugs.
